# GymProcess

Bot de **Telegram** para registrar entrenamientos en lenguaje natural, ver la última sesión por grupo muscular, medir progreso (récords, 1RM, volumen, estancados) y competir sanamente con amigos (resumen semanal, rankings, retos).

Stack: Telegram → **n8n** (self-hosted) → **Google Sheets** → Apps Script (tablero). IA gratuita: Gemini Flash-Lite y Groq.
